04 · Where the data lives

One SQLite file. The database guards the rules.

  • One file per computer. Nothing in the cloud.
  • CHECK constraints and partial unique indexes enforce the rules.
  • Migrations run on startup. Published ones are never edited.

05 · One click, end to end

Optimistic UI with rollback

  • The screen updates first. SQLite writes after.
  • Actions run in a promise queue, so fast clicks never race.
  • If the write fails, the previous snapshot comes back.

function run(plan) {
  queue = queue.then(async () => {
    const prev = snapshot.current
    const { next, save } = plan(prev)
    show(next)        // optimistic
    try {
      await save(api)
    } catch {
      show(prev)      // rollback
    }
  })
}
